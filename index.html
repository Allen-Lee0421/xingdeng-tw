專案總覽 (Executive Summary)

一、 專案背景與宗旨

「光曜星樞 (Singularity Nexus Technology, SNT)」旨在提供企業級 B2B AI 自動化解決方案、系統維運與「爛尾樓救援」服務。本專案透過 Build in Public（公開建構）策略，將實體工程管理的風險控制與解構邏輯導入軟體系統，透過記錄修復 abandoned/爛尾專案的真實過程作為核心行銷素材，並打造全天候自動化運行的「SNT 雲端辦公室」。

二、 三大核心目標

1. 品牌定錨與合規

完成 SNT 官網全面煥新，建立多語系識別與嚴格的法律免責防護屏障 (privacy.html)。

2. Build in Public 行銷

錄製並剪輯「Vercel 爛尾樓救援」系列實錄，建立權威專業形象與獲客閉環。

3. 雲端辦公室與 SDK

建立 5 大職能部門、6 位 AI 數位員工的分工體系，並透過 SDK 實現客戶端一鍵連通。

客戶端一鍵連動模組：SNT Nexus SDK (Trojan Horse Strategy)

一、 嵌入腳本與零摩擦除錯 (Zero-friction Debugging)

所有救援或新建專案均導入 snt-nexus-badge.js 輕量化模組。當客戶點擊「一鍵呼叫雲端客服」時，系統自動打包傳送 Client ID、網址、裝置資訊及 Console Error Log 給 AI-00 星樞總調度官。

// 在客戶網站 </body> 前嵌入 SDK
<script src="https://xingdeng.tw/sdk/snt-nexus-badge.js"></script>

二、 病毒式引流與二次銷售閉環

  • 反向鏈結 (Backlink): Badge 標示 Powered by SNT，帶追蹤參數跳轉官網獲取 B2B 流量。
  • 二次增修轉化: 當客戶提增修，AI-00 自動轉派 AI-01 業務專員開立增修單。
  • 案例庫去識別化: 完工工單自動去除敏感數據，交由 AI-02 生成 Build in Public 素材。
